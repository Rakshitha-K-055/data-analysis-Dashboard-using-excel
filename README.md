# Banking Data Analysis Dashboard

## Project Overview

This project focuses on analyzing banking data using Microsoft Excel to generate meaningful business insights. An interactive dashboard was developed to track key banking metrics, analyze customer information, and visualize important trends to support data-driven decision-making.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## Key Features
- Interactive banking dashboard
- KPI analysis and performance tracking
- Customer data analysis
- Banking transaction analysis
- Trend analysis and visualization
- Dynamic filtering using slicers
- Data-driven business insights

## Key Learnings
- Data cleaning and preparation
- Creating interactive dashboards in Excel
- Analyzing banking data using Pivot Tables
- Building visual reports using Pivot Charts
- Identifying trends and generating business insights

## Conclusion
This project demonstrates my practical skills in data analysis, Excel dashboard development, data visualization, and transforming raw banking data into meaningful insights for business decision-making.
